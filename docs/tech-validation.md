# 技术验证结论：主网拓扑手绘 + 影响范围分析

> 验证日期：2026-07-11（更新：一站一图 + 跨站分析）  
> 范围：总览↔站内视图、手绘主接线、开关分合、跨站电气连通影响分析  
> 不在范围：文档解析、AI 处置问答、拓扑图片识别、母线/间隔模板插入 UI

## 1. 验证目标与通过标准

| 项 | 约定 |
|---|---|
| 目标 | 证明「一站一接线图 + 总览钻取 + 分合状态跨站连通分析」可行 |
| 通过标准 | 总览 3 站可进出；站内主接线可分析；跨站影响可列出并跳转高亮；分闸阻断跨站传播 |

## 2. 已实现能力

- **总览 ↔ 站内同页切换**：点站进站内，顶栏返回总览（无路由）
- **一站一图**：A 单母 / B 双母 / C 桥形占位样例，各站独立 `StationDoc.graph`
- **联络线绑定边界端口**：总览可拖站、增删联络线；两端强制选站内边界设备
- **跨站影响分析**：联合拓扑 + 分合导通；结果含受影响站/联络线；可跳转邻站高亮
- **D5000 风格单线图元**：电压色、合红分绿、刀闸斜刀、主变双圆等
- **持久化**：localStorage 分 key；当前层 JSON 导/导；整包 zip 导/导
