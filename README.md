# 主网拓扑手绘 · 影响范围分析（技术验证）

网页端手绘主网拓扑（D5000 核心能力子集），按开关分合状态做电气连通分析，标出受影响岛及电源侧 / 负荷侧。

本阶段**不做**文档解析与 AI 问答。

## 快速开始

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。

```bash
npm test      # 连通分析单测
npm run build # 生产构建
```

## 操作说明

1. 默认加载「3 站简化主网」样例
2. **分合切换**：点击断路器/刀闸切换开合
3. **设故障点**：点击设备标记故障
4. **分析影响**：高亮电源侧（蓝）、负荷侧（橙）、故障点（红）
5. 支持导出/导入 JSON、localStorage 保存

详见 [docs/tech-validation.md](docs/tech-validation.md)。
